# YOU-GO-RENT
 

YOU-GO-RENT je web aplikacija koja omogućava korisnicima jednostavnu i brzu rezervaciju vozila za najam. Aplikacija korisnicima pruža pregled dostupnih vozila uz informacije o svakom vozilu, te jednostavno kreiranje i upravljanje rezervacijama. Osim korisničkog sučelja za rezervaciju, YOU-GO-RENT ima i administratorski dio koji omogućava upravljanje korisnicima, vozilima, rezervacijama te praćenje aktivnosti i pregleda statistika. Aplikacija korisnicima također omogućava pregled poslovnica i kontakt informacije, kao i mogućnost online plaćanja ili rezervacije vozila za preuzimanje u poslovnici. YOU-GO-RENT objedinjuje sve funkcionalnosti potrebne za brzo i sigurno iznajmljivanje vozila na jednom mjestu.
